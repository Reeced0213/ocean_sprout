# ocean_sprout
Productivity App Development Project using Swift/SwiftUI

Ocean Sprout is a study-focused iOS application that combines productivity and gamification. Users complete focused study sessions and are rewarded with fish that can be added to their virtual aquarium.

## Overview

Ocean Sprout is designed to make studying more engaging by turning completed study sessions into progress within a virtual aquarium.

Instead of simply tracking study time, the application provides a visual reward system that encourages users to continue building their aquarium as they complete more sessions.

## Features

-  Study timer for focused sessions
-  Unlockable fish after completing study sessions
-  Virtual aquarium for displaying collected fish
-  Study session tracking
-  Simple and interactive SwiftUI interface
-  Designed for iOS

## Technologies

- Swift
- SwiftUI
- Xcode
- iOS
- Git
- GitHub

## How It Works

1. Open Ocean Sprout.
2. Start a study session.
3. Focus on studying while the timer runs.
4. Complete the study session.
5. Unlock a fish as a reward.
6. Continue completing sessions to grow your aquarium.
